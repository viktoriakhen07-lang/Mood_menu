# MoodMenu

Сайт кафе, который подбирает блюда по настроению, бюджету и допустимой остроте.
Бэкенд — Node.js + Express, фронтенд — чистые HTML/CSS/JS. ИИ — Claude API (необязательно).

## Запуск в Visual Studio Code
1. Установите Node.js 18+ (https://nodejs.org).
2. Откройте папку проекта: File → Open Folder.
3. Терминал (Ctrl+`) → `npm install`
4. Скопируйте `.env.example` в `.env`, впишите `ADMIN_PASSWORD` и (по желанию) `ANTHROPIC_API_KEY`.
   Без ключа подбор работает по правилам настроения, без ИИ.
5. `npm start` (или `npm run dev` — перезапуск при изменениях)
6. Сайт: http://localhost:3000 · Админка: http://localhost:3000/admin.html

## Структура
- `server.js` — сервер: меню (CRUD), загрузка фото, подбор блюд (правила + Claude)
- `data/menu.json` — меню (редактируется через админку)
- `uploads/` — загруженные фото блюд
- `public/index.html, app.js` — страница гостя
- `public/admin.html, admin.js` — админка: добавить блюдо, загрузить фото, категория, острота (0–3), горячее/холодное, сладкое, подходящие настроения
- `public/style.css` — оформление

## Как работает подбор
1. Отбор по бюджету и допустимой остроте.
2. Баллы по правилам настроения (`MOODS` в `server.js`). Например, «грустно» = сладкое + горячее, без сильной остроты; «злюсь» = острое 2–3 или холодный напиток.
3. Claude выбирает 1–3 блюда (можно комбо в рамках суммы) и пишет пояснение; сервер проверяет, что блюда настоящие и сумма не выше бюджета.
4. Нет ключа или ИИ не ответил — берутся лучшие по баллам.

Новое настроение: добавьте объект в `MOODS` в `server.js`.

## Чат с Gemini
На странице есть блок «Поговорить с ИИ-официантом»: гость переписывается с Gemini, тот уточняет настроение, сумму и отношение к острому, и после диалога предлагает блюда карточками.
1. Получите ключ в Google AI Studio: https://aistudio.google.com/apikey
2. Впишите его в `.env`: `GEMINI_API_KEY=...` (название модели — в `GEMINI_MODEL`; если ответит ошибкой, проверьте актуальное название в AI Studio).
3. Перезапустите сервер (`Ctrl+C`, затем `npm start`). В консоли появится «Чат: Gemini включён».

Как это устроено (`/api/chat` в `server.js`): браузер присылает историю диалога, сервер добавляет системную инструкцию с меню и правилами настроений и просит Gemini вернуть JSON `{reply, budget, picks}`. Сервер проверяет, что блюда настоящие, есть в наличии и укладываются в названный бюджет. Ключ в браузер не попадает.
